# Medium Widget

## Description

Medium Widget is a customizable component that allows you to embed and showcase Medium articles on your website or application. The widget provides a clean interface for displaying article previews from Medium based on topics or specific content that you choose.

## Features

- **Topic-based filtering**: Display content based on specific topics (e.g., technology)
- **Multiple article display**: Showcase multiple articles in a scrollable format
- **Article previews**: Each preview includes:
  - Article title
  - Featured image (when available)
  - Brief introduction text
  - "Read More" links that direct to the full articles on Medium
